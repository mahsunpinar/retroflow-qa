# AI Cheat Sheets: Test Engineer

Short, practical guides for the AI tools that matter most for your day-to-day work as a test
engineer, whether you write automated tests or work manually. These are not required reading
before the workshop, but if you have little or no experience with AI tools, start here rather
than jumping straight into the exercises.

If you already use these tools regularly, skim them anyway: there may be a feature you haven't
tried.

## What's here

- [`github-copilot-for-testing.md`](github-copilot-for-testing.md): the core tool for the
  automation-focused parts of the day.
- [`postman-ai-postbot.md`](postman-ai-postbot.md): the AI features built into Postman, a tool
  most of you already use daily.
- [`claude-code-cli.md`](claude-code-cli.md): a terminal-based alternative to Copilot, useful if
  you have access to it.
- [`what-is-mcp.md`](what-is-mcp.md): what the "hosted MCP server" you'll connect to in Block 3
  actually is and why it matters.
- [`ai-for-manual-testing.md`](ai-for-manual-testing.md): using AI chat tools for exploratory
  testing and manual test work, no automation required.

If something breaks and these guides don't cover it, see `../../ai-tooling-fallback.md` or ask
your coach.
